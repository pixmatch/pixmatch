# Logic file map

- `types.ts`: canonical data contracts and status model.
- `color/rgbToLab.ts`: sRGB gamma decoding, XYZ D65, CIELAB, image conversion.
- `color/ciede2000.ts`: CIEDE2000 perceptual distance.
- `segmentation/phaseClassifier.ts`: reference-phase classification.
- `segmentation/segmentFrame.ts`: complete per-frame segmentation pipeline.
- `segmentation/morphology.ts`: ROI-aware morphology and hole filling.
- `segmentation/connectedComponents.ts`: component extraction/filtering.
- `geometry/bounds.ts`: vertical physical boundary extraction.
- `geometry/metrics.ts`: area and boundary continuity.
- `calibration/calibration.ts`: explicit mm/pixel calibration and physical conversion.
- `calibration/uncertainty.ts`: uncertainty propagation.
- `quality/confidence.ts`: diagnostic confidence calculation.
- `execution/processFrame.ts`: scientific single-frame executor.
- `execution/processBatch.ts`: batch executor and optional interpolation.
- `worker/engine.worker.ts`: worker-side execution.
- `worker/client.ts`: UI-safe worker client.
- `audit/audit.ts`: audit validation.
- `export/export.ts`: CSV/JSON scientific export.
- `validation/referenceTests.ts`: basic scientific self-checks.
